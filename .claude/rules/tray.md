# `tray_status.py` — the tray icon

A pystray loop that polls the PCSS web UI (`https://localhost:6547`). **TLS is pinned, not disabled**: `PCSSClient` saves the server's self-signed cert to `output/pcss_cert.pem` on first connection, verifies against it, and re-pins once on `SSLError` (`_request` wraps every call). The **password is stored in the OS keyring** (Windows Credential Manager, service `stateOfUPS-PCSS`); a plaintext password in `credentials.txt` is migrated into the keyring on first run and the file line is blanked. `PCSSClient` handles the Java form-token login (`j_security_check`), re-logs in on `SessionExpired`, and polls less often on `UserAlreadyConnected` (another session holds the login). `parse_status()` extracts the battery percentage from Spanish-locale HTML; `render_icon()` draws the icon. `AlertWatcher` tails `output/alerts.log` (starts at EOF so history never re-notifies, resets on truncation, 30-minute cooldown) and returns **every** unseen line in a poll — a single analyzer run can append both an anomaly line and the weekly digest, and both must be delivered, not just the last. `notify_alert` fans each line out to a tray toast (`icon.notify()`, always) and, when `[alerts] webhook_enabled` is set and a URL is stored in the keyring, a fire-and-forget webhook POST on its own daemon thread (roadmap item 23 — `maybe_send_webhook`/`send_webhook`; a slow or failing webhook never delays the toast, and failures are logged by class/status only, never the URL). The webhook URL lives only in the OS keyring (service `stateOfUPS-PCSS`, entry `webhook-url`): set or clear it with the one-shot CLI commands `python tray_status.py --set-webhook-url` / `--clear-webhook-url` (each does its job and exits without starting the tray). The right-click menu also has an **"Actualizar dashboard"** item (roadmap item 24 — `run_analyzer_now`/`SingleFlightRun`) that runs `analyze_ups.py` in the background on a worker thread (single-flight: a second click while one is active is rejected with a toast; passes `--no-snapshot` when the daily scheduled run already recorded today), then toasts on completion or failure. The tray reads the same `config.toml` the analyzer does, anchored to the script dir (`_load_tray_config`) rather than the process CWD, so `webhook_enabled` reaches it whatever the launch CWD. Single-instance mutex; file-only logging.

`credentials.txt` holds username/url/poll (gitignored). Delete `output/pcss_cert.pem` to force a re-pin (e.g. after a PCSS reinstall).
