# Dashboard chart engine (`pcss/charts.js`)

Dark card-grid page (ported from the Claude Design project "PowerChute UPS Dashboard Redesign"): header + health pill, a five-card KPI row with sparklines, five titled sections on a 12-column grid, HTML reference tables, and a footer. Charts are **dependency-free inline SVG** rendered client-side by `pcss/charts.js` — Plotly is gone and the page makes zero network requests. The contract:

- **Python computes, JS renders.** `build_dashboard()` embeds one JSON payload through a single `__DASH_DATA__` token in `charts.js`. The panel keys are defined by the payload built in `pcss/dashboard.py` and pinned by `tests/harness.py:PANELS`. Each card is a `#panel-<key>` container. A `None` panel renders a client-side empty-state note. The payload also carries `episodes` (on-battery spans, amber `ep-strip` above the red gap strip), `lost` (lost-telemetry stretches — PCSS up, UPS link down — grey `lost-strip` above the episode lane, same epoch-ms pair shape as `gaps`), `annotations` (dated lifecycle markers, item 26), `strings` (localized chart labels — `[dashboard] language = "en" | "es"`, table in `pcss/dashboard.py`), heatmap `dayKeys`, `meta.default_preset_days` (30-day preset on load once history exceeds 45 days), and `meta.lost_incidents`/`lost_hours`/`lost_est_kwh`. Per-panel extras: `xbreak: true` (lv/ul/pw/bv/bc) makes the series paths start a new subpath instead of drawing across a `gaps`/`lost` span (span-based, never point-spacing-based, because decimation legitimately spaces kept points far apart; a series can opt out with `nobreak`, e.g. the bv trend line, and a stranded single-sample segment renders as a dot), and `recon` (lv/ul/pw) carries per-stretch `{x, mean, lo, hi}` band segments: the estimated mean ± 2σ from the healthy hour-of-day profile, drawn as a grey `recon-band` + dashed `recon-mean` under the measured series with an "estimated" legend chip (`recon-chip`) that toggles them.
- **Timezone contract:** timestamps cross the boundary as **epoch-ms integers with the log's naive local wall-clock encoded as if UTC**, and charts.js formats labels with `getUTC*` only — labels always match the log regardless of browser timezone. `tests/test_chart_payload.py` pins this.
- **Interactions:** hover crosshair + tooltip (click pins, Esc unpins); inside a data hole on an `xbreak` panel the tooltip stops snapping to a sample that can be days away: a `lost` span reports "data lost (UPS link down)" with the interpolated band estimate (`~120.5 V`), any other gap says "no data (monitoring off)" — within 45 min of a hole's edge the edge sample still answers; the `sync: true` flag marks the crosshair-mirror group ONLY — zoom/pan state is strictly per panel; hovering a sync panel also outlines the matching day row + hour cell in the heatmap (`highlightHeatmap`). On the hovered chart: drag ALWAYS zoom-selects (never a mode-dependent pan), `Shift`+drag pans, wheel zooms around the cursor, double-click / `reset` pill / `0` restores. Touch: a drag is claimed only on horizontal intent (vertical swipes scroll), two fingers pinch-zoom around their midpoint, a tap pins the tooltip, and `@media (pointer: coarse)` keeps the card tools visible. Chart boxes are keyboard-focusable (`tabindex`, `role="img"`, aria-label with a Python-generated data summary); focus targets the keyboard shortcuts without hover. The `All·30d·7d·24h` preset pills by the Power Quality header are the one global control: they set every time panel's own window, each anchored to its own newest sample (`applyPreset`); `__chartsDebug.setWindow` is the equivalent test hook. The active preset or per-panel zooms live in the URL hash (`updateHash`/`restoreFromHash`, base-36 ms via `history.replaceState`; malformed hashes fall back silently), alongside the theme override (`t=`, item 30) and the Period Comparison selection (`c=`, item 22). The Line Voltage card gets a `tool-anom` flag button when anomalies exist (`jumpAnomaly` cycles clustered anomalies at ±6 h padding). Legends toggle series; dense series are min/max-decimated to ~2 points per pixel and re-decimated per window change; DataLog gaps render as slim strips on the x-axis (class `gap-strip`), on-battery episodes as amber `ep-strip`. Each card's hover menu exports PNG (SVG→canvas) and CSV (always en-US machine-standard, regardless of language), and expands into a lightbox (a second view of the same panel — gestures there act on that panel only). The header `⎙ pdf` button prints the page (`@media print` stylesheet); `[dashboard] refresh_minutes` adds a meta refresh. Charts draw in once at load (clip-path sweep, skipped under `prefers-reduced-motion` / `?noanim=1`). `Enter` toggles a keyboard sample-inspect mode on a line panel (item 21): arrow keys step through samples and read each into an aria-live region, `Esc` exits (as it also unpins the tooltip and closes the lightbox). The header theme toggle cycles auto/dark/light (item 30), redrawing chart ink from the active palette. The Period Comparison card's selector (item 22) chooses which past billing period the current one overlays (previous · same period last quarter · any specific period). The `ev` event-timeline panel (item 20) draws a dot per event on one categorical row per category, and ships power and battery visible with the communication/monitoring housekeeping rows hidden by default (its legend toggles them).
- **Test surface:** `window.__chartsDebug` (`ready`, `panelKeys`, `xwin`/`fullXwin`/`setWindow`, `zoom`, `isZoomed`, `hover` — which reports `hole: "lost"|"gap"` with empty `rows` inside a data hole, `pinned`, `hidden`, `lost`, `reconHidden`, `lightbox`, `anomalyClusters`, `jumpAnomaly`, `inspect`, `cmpSelection`/`setCmpSelection`, `themeMode`/`theme`/`setTheme`/`cycleTheme`, `resetAll`) — the E2E suites and the between-test reset drive this. `resetAll` also clears the permalink hash, the anomaly-jump cursor, the inspect and cmp selections, the estimated-band toggle, and the theme override (back to the config default).
